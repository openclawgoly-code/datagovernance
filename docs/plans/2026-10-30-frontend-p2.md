# 数据治理 P2 计划：资产语义、质量、访问与外部目录

- 日期：2026-10-30
- 状态：5 个 P2 changes 已创建，待实施
- 前置：P0/P1 的 10 个 specs 已实现并归档
- P0/P1 计划：`docs/plans/2026-10-30-frontend-p0.md`、`docs/plans/2026-10-30-frontend-p1.md`

## 1. 目标

P0/P1 解决了“看见资产、血缘、敏感、历史、看板和工作台”的问题。P2 补 P0 明确留下的治理底座：

1. 资产有业务域、owner、管家、认证状态；
2. 业务术语可维护并绑定资产/字段；
3. 资产有内置质量规则、运行历史和分数；
4. 敏感数据有带原因/时限/审批的临时访问通道；
5. 真正接入 HMS/Glue External Catalog（元数据，不查数据）。

## 2. Changes

| Change | 能力 | 依赖 | 数据库 |
|---|---|---|---|
| `p2-asset-ownership-certification` | 业务域、owner、管家、认证 | `asset-catalog-detail` | V27 |
| `p2-business-glossary` | 业务术语、绑定、发布 | ownership（domain） | V28 |
| `p2-asset-quality-observability` | 质量规则、运行、分数 | 目录、owner/domain 展示 | V29 |
| `p2-sensitive-access-request` | 临时明文访问申请/审批/grant | sensitivity、query history | V30 |
| `p2-external-catalog-hms-glue` | HMS/Glue 只读目录采集 | catalog、ownership | V31 |

## 3. 实施顺序

1. **资产治理**：先建业务域和治理表，后续术语/质量/外部资产都复用；
2. **业务术语**：依赖 domain，先做术语 CRUD 与资产绑定；
3. **质量可观测**：规则、运行、分数；先支持内置规则，不接告警；
4. **敏感访问申请**：接入 Query Gateway 脱敏链路，先做类别/级别级 grant；
5. **External Catalog**：HMS/Glue Provider，最后接入外部资产到 P2 治理视图。

质量与访问申请可并行；External Catalog 也独立，但建议在目录/治理字段稳定后做。

## 4. 数据库与权限

迁移：

```text
V27  md_business_domain, md_asset_governance
V28  md_glossary_term, md_glossary_binding
V29  md_quality_rule, md_quality_run
V30  gv_access_request, gv_access_grant
V31  md_catalog_source.credential_id；data_source_id 可空
```

新增权限：

```text
metadata:asset:govern
metadata:glossary:read / manage
metadata:quality:read / manage
metadata:access:request / approve
```

角色：

- admin/developer：治理、术语、质量、审批、外部目录管理；
- viewer：资产/术语/质量只读，可提交访问申请，不可审批。

## 5. 统一约束

- 所有新端点走 `WorkspaceContext`；
- 治理结论不要写进采集事实表；采集刷新不能覆盖 owner/domain/认证；
- 质量分数只覆盖已配置规则，不能表述为“全量数据质量”；
- 访问 grant 在 Query Gateway 生效，导出复用 ask，不允许旁路；
- External Catalog 只做元数据采集，不宣称支持 StarRocks 外部表查询；
- 前端复用 P0/P1 的 `PageHeader`、`FilterBar`、`EntityLink`、`StatusTag`、`DatasetSearchSelect`、`MetadataPanel`。

## 6. 验收口径

- 资产治理：配置 owner/domain/认证后刷新 Catalog 不丢；非成员 owner 被拒；
- 术语：大小写重复 term 被拒；字段绑定校验；资产详情只显示 PUBLISHED；
- 质量：内置规则在合成数据上通过/失败正确；部分失败不阻断；分数与权重一致；
- 访问申请：自审批禁止；批准后 grant 到期/撤销生效；页面与导出脱敏一致；
- External Catalog：HMS/Glue 采集 database/table/column/partition；认证失败保留旧快照；不复制数据；
- 每个 change：`pnpm type-check`、`pnpm build`、`mvn -pl backend/dg-app -am test` 通过。

## 7. 本批不做

- 看板自由拖拽/版本回滚；
- 查询历史快照/PDF 导出；
- 工单流转/SLA/负责人分派；
- 表级血缘关系细分；
- 资产级/行级数据 ACL；
- 外部表数据查询（StarRocks External Catalog 接入留 P3）。
