# 前端 P0：数据资产与治理体验

- 日期：2026-10-30
- 状态：`frontend-p0-foundation`、`asset-detail-page`、`lineage-workspace` 已实现并归档；其余 4 个 change 待实施
- 设计元语：`frontend/DESIGN.md`
- 架构元语：`ARCHITECTURE.md`
- 关联：`SPACE-MODEL.md` O.1

## 1. 决策

已确认：

1. **P0 只基于现有后端能力**，不新增术语/工单/质量模型；
2. 优先用户是 **业务分析人员 + 数据管家**；
3. **资产详情使用路由页** `/metadata/assets/:id`，抽屉只做快速预览。

P0 目标：把已经存在的 Catalog / Lineage / Sensitivity / Insight / Dashboard 能力补齐为可日常使用的前端工作流。

## 2. 角色与首页

### 3.1 菜单种子（V25）

```text
menu:metadata:lineage        /metadata/lineage
menu:metadata:sensitivity    /metadata/sensitivity
menu:insight:queries         /insight/queries
```

- 三个 read 权限授予 admin / developer / viewer；
- 扫描/复核沿用 `metadata:sensitivity:scan/review`；
- 血缘维护沿用 `metadata:lineage:manage`。

菜单仍由 `pf_permission` 下发，前端只登记静态路由与 `meta.permission`。

## 4. 资产详情页

```text
Header
  qualifiedName / kind / format / source
  rowCount / columnCount / size / updatedAt
  动作：复制链接、去问数、打开血缘

Tabs（?tab= 同步 URL）
  概览 | 字段 | 血缘 | 敏感 | 分区
```

### 4.1 概览

- 描述、来源、位置、格式、schema hash；
- 行数、字段数、分区数、最近更新时间；
- properties JSON 折叠；
- 右侧 MetadataPanel：owner/domain/认证状态（P1 前显示未配置）。

### 4.2 字段

- 表格：序号、字段、原始类型、规范类型、约束、注释、敏感级别；
- 字段行点击打开字段抽屉：
  - 字段元数据；
  - 敏感标签 + 复核入口；
  - 字段血缘入口；
  - 复制字段 ID。

### 4.3 血缘

- 默认取数据集第一个字段的列级血缘；
- 字段选择器切换；
- “打开完整血缘”跳 `/metadata/lineage?columnId=...`。

### 4.4 敏感

- 当前数据集字段标签；
- 级别、类别、状态、证据；
- 有 `review` 权限时显示复核；
- 链接到敏感工作台。

### 4.5 分区

- 分区路径、值、文件数、大小、行数；
- 仅 Parquet 数据集；JDBC 显示空状态。

### 4.6 API

```text
GET /api/v1/metadata/catalog/datasets/{id}
GET /api/v1/metadata/catalog/datasets/{id}/columns
GET /api/v1/metadata/catalog/datasets/{id}/partitions
GET /api/v1/metadata/sensitivity/columns?datasetId=...
GET /api/v1/metadata/lineage/columns/{columnId}/upstream
GET /api/v1/metadata/lineage/columns/{columnId}/downstream
```

目录列表现有抽屉保留为快速预览，增加“打开详情”。

## 5. 血缘工作台

```text
控制条
  资产/字段选择
  方向：上游 / 下游 / 双向
  深度：1–3
  节点类型过滤
中央：ECharts graph
右侧：节点详情 + 影响列表
```

- P0 只做列级血缘；后端没有表级血缘端点；
- 合并 upstream/downstream 节点与边，去重；
- 点击节点显示 qualifiedName、字段、父表、资产详情链接；
- 影响列表调用 `/columns/{id}/impact`；
- 超过 100 节点默认收敛为 2 层并提示；
- 不支持人工补录边 UI，避免误操作。

## 6. 敏感数据工作台

### 6.1 规则

- 名称、类别、级别、检测方式、优先级、启用状态；
- P0 只读。

### 6.2 字段标签

筛选：

- L1–L4；
- SUGGESTED / CONFIRMED / REJECTED；
- 数据集选择器。

表格：

- 字段、数据集、类别、级别、状态、置信度、检测方式、时间；
- 操作：复核。

复核抽屉：

- 证据 JSON；
- 确认 / 拒绝；
- 调整级别；
- 提交后刷新并提示审计已记录。

顶部：

- 发起扫描（全工作区/指定数据集）；
- P0 不展示扫描历史（后端无列表接口）。

## 7. 查询历史

- 表格：问题、用户、状态、行数、耗时、脱敏列、时间；
- 详情抽屉：完整 SQL、数据集、脱敏列、错误信息；
- 有 `insight:ask` 时提供“重新执行”；
- 重新执行必须重新走 `/insight/ask`，不复用旧结果；
- P0 客户端过滤状态/关键词，分页走服务端。

## 8. 看板补全

- 版本：已有列表弹窗；不做回滚（后端未实现）；
- ACL：新增抽屉，调用 GET/POST/DELETE ACL；
- 排序：上移/下移，调用 `PATCH /{id}/items/{itemId}`；
- 刷新：手动 + 60s 自动刷新已有。

## 9. 工作台

按权限显示卡片，不请求无权限模块：

| 卡片 | 数据源 |
|---|---|
| 数据源健康 | 数据源列表/状态 |
| 失败执行 | `/api/v1/executions?status=FAILED` |
| 未处理告警 | `/api/v1/governance/alerts/summary` |
| 待复核敏感 | `/api/v1/metadata/sensitivity/columns?status=SUGGESTED` |
| 最近问数 | `/api/v1/insight/queries` |
| 最近资产 | 目录数据集列表 |

区块：

- 需要处理：失败执行 + 未处理告警 + 待复核标签；
- 最近问数 3–5 条；
- 最近更新资产 3–5 条；
- 快捷入口：智能问数、数据目录、敏感复核。

## 11. 工作流

### 11.1 找可信数据

```text
登录 → 选空间
  → 工作台/数据目录
  → 搜索/过滤
  → 资产详情（概览 → 字段 → 血缘 → 敏感）
  → 问数 / 导出 / 打开看板
```

### 11.2 敏感复核

```text
扫描 → SUGGESTED
  → 敏感工作台
  → 复核确认/拒绝/调级
  → 标签更新 + 审计
  → 资产详情/问数脱敏生效
```

### 11.3 血缘影响

```text
资产详情 → 字段血缘
  → 上游/下游/双向
  → 点击节点看详情
  → 影响列表
  → 复制清单 / 通知下游
```

### 11.4 问数到看板

```text
选数据集 → 问数
  → 摘要 → 图表 → 表格 → SQL
  → 保存看板 / 导出 CSV/XLSX
  → ig_query_log + 审计
```

### 11.5 看板 ACL

```text
看板详情 → ACL
  → 输入用户名 + READ/MANAGE
  → 保存
  → 非授权用户列表不可见
```

- PDF 导出；
- 真正 External Catalog。

## 15. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 血缘接口只到列级 | 无法做表级总览 | P0 明示列级；P1 补表级端点 |
| 1000 表数据集选择器过重 | 页面卡顿 | 服务端搜索/分页，不一次拉全量 |
| 敏感复核无批量接口 | 管家效率低 | P0 单条；P1 批量 API |
| 现有目录抽屉与详情页重复 | 维护两份 | 抽屉只保留摘要和“打开详情” |
| 跨空间/权限遗漏 | 数据泄露 | 所有 API 走 WorkspaceContext + 权限码，前端 fail closed |
